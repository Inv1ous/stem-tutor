## New lesson-note lines

![[Assets/9701/9701-13-1-fig-locants.png]]
*Figure: Numbering a branched chain from each end: the methyl group takes the lower locant, so the name is 3-methylhexane (source: 9701 c13.1, p.9)*
Notice that both numberings are legitimate ways to count the six-carbon parent chain, and that it is the branch position alone that decides between them: 3 beats 4, so only 3-methylhexane is the systematic name (written without a space).
