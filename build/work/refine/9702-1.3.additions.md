## New lesson-note lines

**Error and uncertainty are different:** measurement error is the reading minus the true value. The true value is usually unknown, so the actual error is usually unknown too. An uncertainty describes an estimated interval within which the true value is expected to lie, reported as measured value $x\pm\Delta x$, where $\Delta x$ is the absolute uncertainty.
For example, repeated lengths $24.6,\ 24.8,\ 25.0\ \mathrm{mm}$ have mean $24.8\ \mathrm{mm}$ and half-range $(25.0-24.6)/2=0.2\ \mathrm{mm}$. Using half the range to estimate uncertainty from the scatter gives $(24.8\pm0.2)\ \mathrm{mm}$, an estimated interval from $24.6$ to $25.0\ \mathrm{mm}$, not a known error of $0.2\ \mathrm{mm}$. Repeating readings and taking a half-range does not remove or reveal a systematic offset shared by all readings.
