## Command words

- **Show that**: Prove a given result; every step must be shown (answer given).
- **Hence**: Use the previous result to reach the answer.
- **Hence or otherwise**: Using the previous result is expected, but any valid method earns the marks.
- **Find**: Work out; method marks need working.
- **Calculate**: Work out from given facts; show working.
- **Prove**: Give a complete logical argument.
- **Sketch**: Draw the shape with key features labelled (intercepts, asymptotes, turning points), not to scale.
- **Exact**: Give the answer in surd, fraction, pi or ln form, not a decimal.
- **Verify**: Show that given values satisfy the statement.
- **State**: Give the answer without working.
- **Explain**: Give reasons in context.
- **Interpret**: Explain the meaning of a result in the context of the question.
