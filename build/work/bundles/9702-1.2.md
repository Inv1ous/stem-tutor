## KCs

### 9702-1.2.1 — SI base quantities and units (factual)
Statement: recall the following SI base quantities and their units: mass (kg), length (m), time (s), current (A), temperature (K)
Prerequisites: 9702-1.1.1 Physical quantities as magnitude and unit
Glossary: si base units, kilogram, metre, second, ampere, kelvin

### 9702-1.2.2 — Expressing derived units (procedural)
Statement: express derived units as products or quotients of the SI base units and use the derived units for quantities listed in this syllabus as appropriate
Prerequisites: 9702-1.2.1 SI base quantities and units
Glossary: derived units, si base units, dimensional consistency

### 9702-1.2.3 — Checking homogeneity with SI units (procedural)
Statement: use SI base units to check the homogeneity of physical equations
Prerequisites: 9702-1.2.2 Expressing derived units
Glossary: homogeneity of equations, dimensional analysis, si base units

### 9702-1.2.4 — SI unit prefixes (factual)
Statement: recall and use the following prefixes and their symbols to indicate decimal submultiples or multiples of both base and derived units: pico (p), nano (n), micro (μ), milli (m), centi (c), deci (d), kilo (k), mega (M), giga (G), tera (T)
Prerequisites: 9702-1.2.1 SI base quantities and units
Glossary: si prefixes, nano, micro, milli, kilo, mega, giga, tera
