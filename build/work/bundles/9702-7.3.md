## KCs

### 9702-7.3.1 — Doppler effect, moving source (conceptual)
Statement: understand that when a source of sound waves moves relative to a stationary observer, the observed frequency is different from the source frequency (understanding of the Doppler effect for a stationary source and a moving observer is not required)
Prerequisites: 9702-7.1.5 Using the wave equation, v = fλ
Glossary: doppler effect, observed frequency, source frequency, moving source

### 9702-7.3.2 — Doppler effect frequency formula (procedural)
Statement: use the expression $f_o = \dfrac{f_s v}{v \pm v_s}$ for the observed frequency when a source of sound waves moves relative to a stationary observer
Prerequisites: 9702-7.3.1 Doppler effect, moving source
Glossary: doppler effect, observed frequency formula, fo = fsv over v plus or minus vs
