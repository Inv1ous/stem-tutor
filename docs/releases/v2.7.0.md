# STEM Tutor v2.7.0 (2026-11-09)

See `CHANGELOG.md` for the full list. Upgrade: pull, run `tutor doctor`, start the tutor. No learner data is migrated;
history, answers and grades are untouched. The question-image sort and the junk flags change the Library catalog only
(old paths remain declared aliases; `question_image_triage.py apply --undo` and `organize_question_library.py rollback`
restore the previous state).

Checks run for this release: app and engine test suites, a real-Terminal resize-during-load run, and the image triage
on the real Library (reviewed by RouteLLM, one call per look-alike group).
