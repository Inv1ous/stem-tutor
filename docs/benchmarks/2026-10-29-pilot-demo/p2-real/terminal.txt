╭─ Tutor-written: Number line picture: even and odd integers alternating and covering all integers─╮
│ Picture the integers as evenly spaced points on a line. Colour them alternately: even, odd,      │
│ even, odd, and so on. Every point gets exactly one colour, so the two cases together cover every │
│ integer with no gaps and no overlaps.                                                            │
│                                                                                                  │
│ The number line picture                                                                          │
│                                                                                                  │
│  • Even integers (multiples of 2) sit at: ..., -4, -2, 0, 2, 4, ...  Call these the 'red'        │
│    points.                                                                                       │
│                                                                                                  │
│  • Odd integers sit at: ..., -3, -1, 1, 3, 5, ...  Call these the 'blue' points.                 │
│                                                                                                  │
│  • Reading left to right, the colours go: red, blue, red, blue, ... For example: -2 (red), -1    │
│    (blue), 0 (red), 1 (blue), 2 (red).                                                           │
│                                                                                                  │
│ Why the alternation never breaks                                                                 │
│                                                                                                  │
│  1 Every even integer can be written in the form below, where 𝑘 is an integer. These are the red │
│    points.                                                                                       │
│                                                                                                  │
│ 𝑛 = 2𝑘                                                                                           │
│                                                                                                  │
│  2 The integer immediately after an even integer is one step to the right. Adding 1 gives the    │
│    blue points.                                                                                  │
│                                                                                                  │
│ 𝑛 = 2𝑘 + 1                                                                                       │
│                                                                                                  │
│  3 The next integer after that is the next red point, because 2𝑘 + 2 equals 2(𝑘 + 1), which is   │
│    even.                                                                                         │
│                                                                                                  │
│ 2𝑘 + 2 = 2(𝑘 + 1)                                                                                │
│                                                                                                  │
│  4 So the pattern restarts every 2 steps. Each pair of neighbouring integers, 2𝑘 and 2𝑘 + 1,     │
│    contains one red and one blue point. As 𝑘 runs through all integers, these pairs tile the     │
│    whole line, so no integer is missed.                                                          │
