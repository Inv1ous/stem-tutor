╭─ In plain words ─────────────────────────────────────────────────────────────────────────────────╮
│ An exact bond energy is for one specific bond in one specific gaseous molecule. An average bond  │
│ energy is the mean for the same type of bond across different molecules. Because the             │
│ surroundings of a bond change its energy, calculations using averages are estimates.             │

╭─ The idea in more detail ────────────────────────────────────────────────────────────────────────╮
│ An exact bond dissociation enthalpy belongs to a specified bond-breaking process in a specified  │
│ gaseous species, such as splitting gaseous hydrogen molecules into gaseous atoms. An average     │
│ bond energy is a mean; a tabulated value commonly averages a bond type over different gaseous    │
│ compounds.                                                                                       │
│                                                                                                  │
│ Molecular environment affects bond energy, so the same bond type need not have the same value    │
│ everywhere. Successive bond dissociations in methane also differ: the mean C–H energy in methane │
│ is one quarter of its total gaseous atomisation enthalpy, not simply the first dissociation      │
│ energy.                                                                                          │
│                                                                                                  │
│ Here exact means specific to a process, not free from experimental uncertainty.                  │

╭─ Tutor-written: Worked example: estimating the enthalpy change of combustion of methane from ave─╮
│ Add up the energy needed to break all the bonds in the reactants, subtract the energy released   │
│ when the bonds in the products form, and you get an estimate of about −818 kJ mol⁻¹ for burning  │
│ methane (using the average bond energies below).                                                 │
│                                                                                                  │
│  1 Write the balanced equation with every substance as a gas, because bond energies refer to     │
│    gaseous molecules. Then draw out the bonds: CH₄ has 4 C–H, 𝑂₂ has O=O, CO₂ has 2 C=O, and H₂O │
│    has 2 O–H.                                                                                    │
│                                                                                                  │
│ CH₄(g) + 2O₂(g) → CO₂(g) + 2H₂O(g)                                                               │
│                                                                                                  │
│  2 Count the bonds broken in the reactants: 4 C–H in one CH₄, and 2 O=O in two 𝑂₂. Use these     │
│    average bond energies: C–H = 410, O=O = 496, C=O = 805 and O–H = 460, all in kJ mol⁻¹.        │
│    Check them against your own data table, as values vary slightly between sources.              │
│                                                                                                  │
│ Unformatted expression:                                                                          │
│                                                                                                  │
│                                                                                                  │
│  $$                                                                                              │
│  \text{Energy in} = (4\times 410) + (2\times 496) = 1640 + 992 = 2632\ \mathrm{kJ\ mol^{-1}}     │
│  $$                                                                                              │
│                                                                                                  │
│                                                                                                  │
│  3 Count the bonds formed in the products: 2 C=O in one CO₂, and 2 O–H in each of two H₂O,       │
│    giving 4 O–H altogether.                                                                      │
│                                                                                                  │
│ Unformatted expression:                                                                          │
│                                                                                                  │
│                                                                                                  │
│  $$                                                                                              │
│  \text{Energy out} = (2\times 805) + (4\times 460) = 1610 + 1840 = 3450\ \mathrm{kJ\ mol^{-1}}   │
│  $$                                                                                              │
│                                                                                                  │
│                                                                                                  │
│  4 Combine them using Δ𝐻 = bonds broken − bonds formed. Breaking bonds is endothermic and        │
│    forming bonds is exothermic, so more energy released than absorbed gives a negative answer.   │
│                                                                                                  │
│ Unformatted expression:                                                                          │
│                                                                                                  │
│                                                                                                  │
│  $$                                                                                              │
│  \Delta H = 2632 - 3450 = -818\ \mathrm{kJ\ mol^{-1}}                                            │
│  $$                                                                                              │
│                                                                                                  │
│                                                                                                  │
│ This is only an estimate. Tabulated values are average bond energies, taken over many different  │
│ molecules, but the energy of a bond depends on its molecular environment.                        │
│                                                                                                  │
│ For example, the C–H bond in methane is not quite the same as in other compounds, and the C=O in │
│ CO₂ differs from C=O in other molecules. Also, the equation here gives gaseous water, whereas    │
│ the standard enthalpy change of combustion refers to liquid water.                               │
│                                                                                                  │
│ The experimental value is therefore noticeably different (roughly −890 kJ mol⁻¹).                │
│                                                                                                  │

╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Example answer ─────────────────────────────────────────────────────────────────────────────────╮
│ The bond energies in a table are average values: each is the mean of a bond type measured in     │
│ different molecules. The actual energy of a bond depends on its molecular environment, so it may │
│ differ from the average. The calculation is therefore an estimate and may not equal the          │
│ experimental value.                                                                              │
