╭─ Tutor-written: Worked example: finding fringe spacing x from x = lambda D / a for a double slit─╮
│ The fringe spacing 𝑥 is the distance between adjacent bright fringes (or adjacent dark ones) and │
│ is found from 𝑥 = 𝜆𝐷/𝑎. Convert every quantity to metres first, then substitute.                 │
│                                                                                                  │
│ Worked example                                                                                   │
│                                                                                                  │
│ Monochromatic light of wavelength 600 nm passes through two slits with separation 𝑎 = 0.40 mm.   │
│ The screen is 𝐷 = 2.0 m from the slits. Find the fringe spacing 𝑥.                               │
│                                                                                                  │
│  1 Convert the wavelength to metres, using 1 nm = 10⁻⁹ m.                                        │
│                                                                                                  │
│ 𝜆 = 600 × 10⁻⁹ m = 6.0 × 10⁻⁷ m                                                                  │
│                                                                                                  │
│  2 Convert the slit separation to metres, using 1 mm = 10⁻³ m. The distance 𝐷 is already in      │
│    metres.                                                                                       │
│                                                                                                  │
│ 𝑎 = 0.40 × 10⁻³ m = 4.0 × 10⁻⁴ m                                                                 │
│                                                                                                  │
│  3 Substitute into 𝑥 = 𝜆𝐷/𝑎 and evaluate.                                                        │
│                                                                                                  │
│ 𝑥 = (6.0 × 10⁻⁷ × 2.0)/(4.0 × 10⁻⁴) = 3.0 × 10⁻³ m                                               │
│                                                                                                  │
│  4 Give the result in a sensible unit: 𝑥 = 3.0 mm. This means that neighbouring bright fringes   │
│    are 3.0 mm apart on the screen, which is easy to see and measure.                             │
