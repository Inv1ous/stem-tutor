# Source verified practice

## Intent and decision

Make original questions usable quickly without paying AI to rewrite or solve every question. The user explicitly chose source-verified practice before detailed skill mapping on 5 November 2026. Unmapped practice never earns adaptive mastery credit. Existing teaching-approved resources and learner history remain unchanged.

## Trigger and source of truth

An explicit import receives registered source PDFs or an existing frozen preparation bundle. All source bytes resolve through AssetLibrary. Run this workflow per source family and source document, not per question. Source-verified means faithful source identity, complete bounded question pixels and verified answer association; it does not certify mathematical correctness of the publisher or detailed skill mapping.

## Workflow

1. Verify issuer/role/identity where available, registered digests and complete page accounting. Preserve the original pixels. Native Cambridge Paper 1 uses its official QID. A PMT compilation without an authenticated exam reference keeps its stable occurrence ID and printed title; never invent a current IAL qualification.
2. Reconstruct question geometry from source bytes. Verify every referenced crop against a fresh source render using one page cache. Independently extract native official MCQ keys using spatial rows and serialized text; both must agree. Preserve context and exceptions. Missing questions, conflicting identities/keys or ambiguous question/answer boundaries hold affected items; global identity faults hold the file.
3. For PMT written questions, match the numbered question and mark-scheme blocks within the same source. Distinguish examiner comments and repeated numbering from schemes. Keep full scheme alternatives and continuations private. Missing or ambiguous rubric matches remain held, not guessed. Use printed question totals as explicitly labelled score authority; do not claim an independently parsed MS total when none exists.
4. Publish immutable source-practice resources through Library registration into a separate source-practice release. Never flip the existing Topicals pointer or rewrite existing resources. Resolve existing canonical identities, report reused versus new items, and quarantine known source-content holds and current guard2 scopes. Preserve all original worker states, guards and aliases.
5. Browse by course and source/paper; use the literal topical title where known. Source-backed practice is separate from the adaptive lesson bank. No inferred detailed KCs and no mastery updates. Show original question media with no answer leakage. MCQs grade from the verified official key after an attempt. Written work unlocks the original scheme for self-marking; AI explanations and marking run only on explicit request through existing AI infrastructure. Concise feedback after correct answers, fuller help on request/incorrect work. Save practice attempts separately, without changing historical learner events or grades.
6. Detailed mapping may be checked later. This workflow does not forge a successful AI extraction or semantic review receipt. Availability, source verification and mastery certification remain distinct.

## Checkpoint and done

No routine per-question human approval. AI inspects actual exceptions or a new ambiguous source format, not every clean item. Stop on unsupported formats with an exact exception ledger. Done requires a usable practice entry, deterministic scoring where supported, private scheme gating, immutable provenance and an observed unchanged mastery/history boundary. Counts distinguish source-verified, held, reused, newly available and mastery-certified items.

## Evaluation

Measure original PDFs through source verification, Library publication and actual practice interaction. Use fixed native MCQ and PMT written fixtures. Record wall time, source/page/image counts, provider tasks and held items. A paired local verifier evaluation uses identical checks and source bytes. Do not infer end-to-end speedup from preparation time, compare different assurance levels as equivalent, or promise all-course completion before a representative published-items-per-minute result.
